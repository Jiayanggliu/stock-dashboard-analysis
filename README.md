# Stock Dashboard Analysis

This project analyzes the performance and risk of selected large U.S. stocks over a two-year period.

The dashboard includes:
- Normalized stock price performance
- 20-day and 200-day moving averages
- 30-day rolling volatility
- Stock return correlations

It is designed for a self-directed retail investor to compare performance, risk, trends, and diversification when making portfolio allocation decisions.

The main analysis is in `stakeholder_dashboard.ipynb`.
